What NO CAL means

NO CAL is about the radio's calibration, not the knobs or keys. Older Melodee releases kept presets where the FM-1 stores it, so some FM-1s lost it.

This page installs a small calibration helper that measures the radio with the AC79 SDK's own routine, then puts Melodee back and saves the result there. Missing factory trims use the SDK's board defaults: a lost factory alignment can't be recreated exactly.

The result is also downloaded as a file. It holds only this FM-1's radio calibration: no music, no pairing keys.

Use a saved calibration

If you saved this FM-1's calibration file, or have its original 1 MiB full-flash backup, restore from it instead of measuring again. Musical backups don't contain the radio calibration. Connect the FM-1 with Melodee running and the radio off.

If a recovery stopped

Nothing is lost. Until Melodee is back, the FM-1 starts the calibration helper (its screen shows READY or KEEP USB CONNECTED) or waits in update mode (UPDATING, or a dark screen). That holds even after switching it off.

Connect it and press Find FM-1: the page offers to finish. If the FM-1 isn't recognised, reinstall Melodee here, then restore the downloaded calibration file.

Recovery diagnostics

If calibration stopped or the FM-1 restarted while the helper ran, read what the helper recorded: its last stage, timing and watchdog resets. Do this before reinstalling Melodee, and send the file with a bug report.
